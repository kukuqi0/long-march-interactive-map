# 红军长征专题交互地图

一个聚焦 1934—1936 年红军长征相关资料的交互地图技术原型。

## 当前范围

当前样例围绕中央红军相关地点、事件、路线和组织信息，提供地图浏览、时间过滤、组织筛选、时间轴、路线播放、确定性与争议方案展示、对象详情，以及声明—证据—来源追溯。界面支持桌面和移动端使用。

项目仍处于资料整理与核验阶段，部分记录是用于验证数据结构和界面交互的演示数据，不应视为完整史料库或最终历史结论。

## 本地运行

需要 Node.js 稳定 LTS 版本和 npm。

```bash
npm ci
npm run dev
```

开发服务器启动后，按终端提示打开本地地址。

## 检查与构建

```bash
npm run lint
npm run format:check
npm test -- --run
npm run build
npm run preview
```

`npm run preview` 用于在本地预览生产构建结果。

## 技术栈

- React
- TypeScript
- Vite
- MapLibre GL JS

## 数据说明

本专题目前仍在资料整理与核验阶段，部分地点、路线及组织信息可能继续修订。项目中的确定性、争议和来源信息按各自维度呈现，不应用数值概率替代史料判断。
